# Termux stow package

This package contains configuration files for Termux app:

- Settings with custom extra keys layout;
- Colorscheme based on Alacritty's [Ayu Dark](https://github.com/alacritty/alacritty-theme/blob/master/themes/ayu_dark.toml) colorscheme.
- JetBrains Mono font patched with Nerd Font icons taken from [here](https://github.com/ryanoasis/nerd-fonts/blob/master/patched-fonts/JetBrainsMono/Ligatures/Regular/JetBrainsMonoNerdFontMono-Regular.ttf).
